# Netflix Titles Analysis using Python

## Project Overview

This project analyzes the Netflix Titles dataset using Python to explore content distribution, ratings, release trends, and other characteristics of movies and TV shows. The project covers data cleaning, exploratory data analysis, KPI creation, dataset merging, and data visualization.

## Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / VS Code

## Project Workflow

- Cleaned and prepared the Netflix titles dataset.
- Inspected dataset structure, data types, missing values, and duplicate records.
- Performed exploratory data analysis (EDA).
- Created KPIs to summarize key metrics.
- Merged relevant datasets for analysis.
- Created visualizations using Matplotlib and Seaborn.
- Analyzed movies vs. TV shows, ratings, release years, and other content trends.

## Key Analysis Areas

- Total number of titles
- Movies vs. TV Shows
- Content distribution by release year
- IMDb rating distribution
- Content ratings
- Runtime analysis
- Missing and duplicate value analysis
- Other Netflix content trends
